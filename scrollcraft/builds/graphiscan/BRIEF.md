# GraphiScan initial website

Self-authored under explicit creative delegation in landingsite.md. User asks
for the initial site based on the current system, with the APK added later.

## Eight topics

1. User direction: sophisticated, minimalist, professional, human-centered,
   educational. References in brief: Apple, Linear, Stripe, editorial design.
2. User journey: Curiosity → Understanding → Empathy → Discovery → Confidence → Action.
3. Authored energy: spacious opening, tactile educational exploration, quiet
   explanation, largest product reveal, useful controls, calm ending.
4. Authored feeling curve: curiosity from an unfinished stroke; recognition from
   handwriting controls; empathy from a short educational passage; clarity from
   actual app screens; confidence from roles/workflow; readiness from release status.
5. Signature: a sentence on ruled paper responds to spacing/alignment controls;
   a continuous blue stroke links the paper motif to the product reveal.
6. User aesthetic: premium editorial, warm white, slate and existing #355C8C.
7. Authored structure: distinct scenes, using a custom annotated-notebook grammar.
   Navigation provides chapter anchors; the hero is a paper-and-type spread;
   the close resolves the original sentence into a learner-centered message.
   No pinned empty spans, video backdrops, scroll hijacking or invented metrics.
8. Assets: supplied glossy mark derivative, actual admin and Expo UI captures
   with documented fictional records. No generated raster or real learner data.

## Peak and grammar

Peak: “It's the site where a handwriting illustration leads into the actual
tools used by the people supporting a learner.” Lives in the product reveal,
the largest composed spread with a real mobile preview and workflow explorer.
No authored silent scroll spans. The other grammars lose because a film/world
is too cinematic for educational reading, a live surface implies public inference,
a poster lacks product depth, a catalog lacks narrative, a split stage implies
a misleading before/after comparison, and strict chaptered editorial excludes
the requested opening illustration. Custom notebook grammar keeps legible scenes.

| Beat | Device | Purpose |
| --- | --- | --- |
| Curiosity | layered paper + stroke reveal | connect writing with understanding |
| Recognition | interactive spacing/alignment | explore without diagnosis |
| Empathy | static editorial passage | give reading space |
| Discovery (peak) | product reveal + selectable workflow | show the actual system |
| Confidence | role explorer + pipeline | explain scope and human review |
| Action | static release plate + closing stroke | honest next step |

Fingerprint gate: registry empty at planning; no prior rows to compare.
Preflight: Node/Chrome available; FFmpeg missing. No video is used. No generation
key needed. Browser verification uses the existing Playwright CLI installation.
Application source is graphiscan/landing-web; this folder holds design planning.

About the Project

GRAPHISCAN supports early detection through handwriting image analysis.

This capstone project aims to support early detection of possible dysgraphia through handwriting image analysis. It is not a replacement for professional diagnosis, but it can assist educators, parents, and support staff in identifying learners who may need further evaluation and intervention.

Responsive web-based access for different user roles.
AI-assisted analysis using handwriting image samples.
Designed to support, not replace, expert evaluation.
